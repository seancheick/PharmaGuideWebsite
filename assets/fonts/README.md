# OG-card fonts

Read at build time by `src/lib/og.tsx` to render social/share images
(satori cannot read the woff2 files `next/font` serves to browsers).

| File | Source | License |
|---|---|---|
| `Geist-Medium.ttf`, `GeistMono-Medium.ttf` | `node_modules/geist` (Vercel) | SIL OFL 1.1 |
| `Newsreader-Italic.woff` | Google Fonts, Newsreader italic 400, opsz 72 | SIL OFL 1.1 |

These are the same families the site renders with, so share cards match the page.
